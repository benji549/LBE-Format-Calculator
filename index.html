Connect this app to Supabase

The code is ready, but config.js still contains placeholder credentials.

  1. Create a Supabase project.
  2. Run supabase/schema.sql in the SQL Editor.
  3. Paste your Project URL and publishable key into config.js.
  4. Host the folder on Netlify, Vercel, Cloudflare Pages, or GitHub Pages.

The service-role or secret key must never be placed in this browser application.
